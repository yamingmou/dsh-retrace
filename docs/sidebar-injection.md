# 侧栏注入显示 —— 实现要点与坑（写下来，后人少走一次）

> 状态：**已交付并真机验证**（2026-09-22）。来源：本线放行件与裁决记录（内部台账可查）。

## 一、★ 最关键的一条发现（别再走死路）
**侧栏会话行的 DOM 里没有任何 session id。**
`[role="treeitem"]` 行元素上只有 `ref / className / role / aria-selected / onClick / draggable / onDragStart`：
**无 `id`、无 `data-*`、无 `aria-label`**，而类名是**构建哈希**（`ozLDBG_sessionRow`）⇒ 换版本即失效。`node.id` **只活在 `onClick` 闭包**里。

**映射在哪**：行由 `SessionNodeItem({ node, … })` 渲染 ⇒ **`node` 在组件 props 里** ⇒
```
从 [role="treeitem"] 取 __reactFiber$*
  → 沿 fiber.return（组件树！不是 DOM parentNode）逐层找 memoizedProps
  → props.node.id → 该行的 session id
```
**两条曾经走错的路（都别走）**：
1. ❌ **扫 DOM `parentNode`** 上的 fiber —— 行元素那层的 props 里没有 `node`，**真机每行都 miss**（实测：`no-fiber:walked=12 …`）；
2. ❌ **按 store 顺序对应** —— 侧栏渲染的是**树**（分组/过滤/折叠）⇒ **DOM 行序 ≠ store 线性序**，**会错配**（错配比不显示更糟）。

**fail-soft 的正确形态**：**取不到就跳过这一行**（**绝不退化成按序猜**）；React 主版本变了 ⇒ 表现应为**完全不注入**（安全侧），并**去重上报**诊断（走了几层、每层 props 键名）。

## 二、四条护栏（都已落地）
1. **fail-soft**：取不到 fiber／取不到映射（`badgeMap` 失败或缓存空）／官方标题已带码／注入异常 ⇒ **该行跳过**；异常全吞，界面保持官方形态；
2. **不静默**：失败**去重**上报（`clientReport` 进宿主日志）；
3. **可退**：开关 `getConfig().sidebarBadge`（默认 on）关掉 ⇒ **不注册 observer 且 `stop()` 抹掉徽标**（免重启）；
4. **公开版不展示谱系标识**：`SIDEBAR_BADGE_PUBLIC_BUILD` **构建期裁剪**（`@public-strip:else`）⇒ **同一份代码两种呈现，不分叉**。

## 三、⭐ 规矩：**内部身份表一律不进发布物，一律运行时取**
**教训**：把谱系标识表（111 条 / `bindings.json`）**构建期内置进 `lib/**`** ⇒ `publish-leaks` 实测 **460 处命中**（`111×会话id形态 + 111×session-id-shape + 108×内部成员谱系标识 + 53×session- 前缀 + 46×化石命名 + 18×裸 id`）。
而且 `publish-leaks` 扫的是**私有树的 npm pack 集合** ⇒ **"私有树内置、投影树裁掉"也救不了**。
**⇒ 规则（立此存照）**：**谱系标识表 / 绑定表 / stable-id 等内部身份表，一律不进发布物，一律运行时取**（本实现取宿主只读路由 **`badgeMap`(111)** + **`titleMap`(375)**）；**构建期裁剪只是退路，不是主路径**。
**这条已被机械强制**：`check-publish-set` / `public-projection` 的发布面闸门会拦住"内部 id 进包"（0 命中才算过）。

## 四、三个已修真缺陷（都会复发，记下来）
1. **走链错**（见 §一）—— 症状：侧栏**毫无变化** + 日志 `no-fiber`；
2. **并排两个码** —— 根因 = **我们自己的 T3 回填把 `[谱系标识]` 写进了官方标题**（218 条里 **56 条**），注入器**只判官方标题为空** ⇒ 又前置一个；点击加载历史后官方标题带码回来 ⇒ "一个变两个"。
   **修**：`CODE_PREFIX` 命中 ⇒ **`skip:title-has-code`**（**码只出一个来源**：官方已带就用官方的）；
3. **重渲染残留** —— `takeRecords()` + `selfOnly` 会让"插入后不再重扫"，**从而挡住去重**；**去重必须在同一次 `scan()` 内完成**（`claimed` 集合 + 收尾按 sessionId 全量核对：同 id > 1 ⇒ 只留第一个）。

## 五、剩余缺口（后置，`§0.11`）
**冷会话仍不默认显示"名字"**（**谱系标识已能不点即显**）。线索：名字**只在官方标题 span 为空时**补，而冷会话那格可能是**占位/工作区名**（非空）⇒ 不补；`isSeeded` 会话列表**结构性不读缓存**；无缓存行会话**只有谱系标识无名字**（**不伪造**）。
**方向**：放宽触发（标题=占位/工作区名时也补我们名字）+ 真机 DOM 断言。
