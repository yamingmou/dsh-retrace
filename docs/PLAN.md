# 下一步方向与计划 · Plan

> 面向使用者与生态伙伴的**产品级计划**（不含实现细节）。最后更新：2026-10-27。
> 已发布能力见 [README](../README.md)；历史版本见 [VERSIONS](../VERSIONS.md) 与 [CHANGELOG](../CHANGELOG.md)；能力路线见 [ROADMAP](./ROADMAP.md)。

## 1. 当前定位（一句话）
`dsh-retrace` 为 agent 会话提供**可回溯、可审计、可恢复**的运营能力：召回/编辑重发、检查点与产物快照、回滚、会话谱系标识，以及发布与安全闸门。

## 2. 近期（下一个版本）
| 方向 | 内容 | 状态 |
|---|---|---|
| 会话谱系标识 | 新建会话自动分配稳定标识；侧栏每会话只显示一个标识（刷新不重复） | 已实现（0.4.135） |
| 显示名与开关 | 允许用户设置会话显示名、并可在设置中关闭谱系标识展示 | 计划中（设置页开关未实现；现可用 `DSH_RETRACE_SHOW_CODES=0` 隐藏展示） |
| 回退体验 | 回退/恢复后的消息在界面中的展示与可编辑性一致性 | 进行中 |
| 大历史会话 | 长会话的读取/回退性能与稳定性（只做产品可见的改善） | 规划中 |

## 3. 中期（方向，不承诺版本）
- **跨会话谱系**：会话之间的父子关系可视化与跨会话追溯（产品层面）。
- **可审计记录**：面向团队的回溯与审计视图（谁在何时回退了什么）。
- **可移植性**：同一套能力在更多宿主上的可移植路径（插件形态优先）。
- **发布与安全闸门**：发布前自动检查（对外内容、版本一致性、包内容）持续完善。

## 4. 明确不做
- 不修改宿主的核心会话写入逻辑；压缩与存储沿用宿主自带实现（不另建）。
- 不做云端托管或远程服务：默认本地、离线可用。
- 不收集用户会话内容用于训练或分析。

## 5. 如何参与
- 问题与需求：GitHub Issues；发布节奏与兼容说明见 [ROADMAP](./ROADMAP.md) 与 CHANGELOG。
