# dsh-retrace 路线图 · Agent 业务层(生产级保证)

> 日期：2026-08-30｜对外发布版（社区/README/dsh-market）。
> 定位一句话：**dsh-retrace 不是一个「撤回插件」，而是 DeepSeek Harness agent 的
> 业务层——会话卫生、可回溯、可审计、可恢复，全部带生产级保证。**
> 本文档是对外口径，可直接引用或贴到 README / 社区帖。

---

## 为什么是「业务层」，不是「功能」

DeepSeek Harness 的 agent 跑在 append-only 事件日志之上。日志是**数据层**，
agent-loop 是**执行层**，而「会话怎么保持健康、怎么回退、怎么审计、坏了怎么修」——
这些与模型、工具、UI 都无关的运营能力，是**业务层**。

| 业务层机制 | 回答的问题 | 现状 |
|---|---|---|
| **卫生**（编辑/中断/并发守护） | 编辑会不会弄脏日志？中断会不会留脏状态？并发写会不会坏文件？ | ✅ 已上线 |
| **可回溯**（版本/时间线/产物回退） | 每次改动属于哪个版本？能不能回到任意点？产物能不能一起回退？ | ✅ 已上线 |
| **可审计**（考古/谱系/分叉） | 会话做过什么？工具输出去哪了？分叉从哪来？ | ✅ 已上线（考古 CLI） |
| **可恢复**（体检/修复/快照） | 日志坏了吗？坏了能修吗？坏的那一刻有备份吗？ | ✅ 已上线（离线修复） |

**一句话**：模型决定 agent 有多聪明，业务层决定 agent 的会话能不能被信任。

## 生产级保证（我们的差异化承诺）

以下每一条都是**已实现并验证**的，不是口号：

### 1. 写安全 —— 编辑永不弄脏日志
- 每次撤回/编辑/重发都过**三层写前校验**（持久化/引擎/插件契约），违约即拦、不落盘
- 编辑前自动停止运行中的 agent（官方 `cancel`/`whenIdle` API），杜绝跨 step 引用
- 轮次间 marker 用临时 step 包裹——**对官方 token meter 始终合法，/compact 永不失效**
- 这是其他「undo / verify」插件没有的写安全维度：它们只读，我们保证写也干净

### 2. 深层体检 —— 不是浅层扫描
- `dsh-log-contract` 30+ 契约规则：token-meter 配对、跨 step 源引用、物理序、inbox 重放…
- **以真实损坏会话当测试集**——能找出让官方 /compact 永久失效的那类问题
- 通用「孤儿 tool call」扫描器看不到的，我们看得到

### 3. 检测 → 修复 → 守护 闭环
- **检测**：离线 `check` 全量规则 + 实时看门狗
- **修复**：`fix` 原地中和问题 marker、裁剪跨 step 引用、重编号——帧级、先备份
- **守护**：watchdog 在并发写入第一时间快照日志到 `snapshots/`

## 路线图（分期）

### ✅ 已上线（0.4.x）
- 撤回 / 编辑重发 / 重新生成（写安全，三层校验）
- 版本时间线 + 产物回退（git 优先 + 快照兜底）+ 跳转
- 分叉图 + 会话谱系（lineage）
- 实时看门狗（并发写入快照）
- 离线体检 30+ 规则 + 修复原语（neutralize / clip-crossstep）
- dsh-market 一键安装（awesome-dsh-plugin 已收录）

### 🚧 开发中（下一版）
- **运行时守护**：订阅会话事件流实时校验，违规即刻标记（不止离线体检）
- **中断轮次治理**：退出前提示未闭合轮次，中断标记入时间线

### 🗺️ 规划中（业务层开放）
- **业务层接口开放**：写前校验 / 中断治理 / 体检修复以独立接口提供，
  **任何 DSH 插件或 agent 都能接入**——业务层从「dsh-retrace 的附带品」
  变成「生态的公共层」
- **跨部署形态**：同一套业务层机制在不同 Harness 部署形态下一致生效
  （Web / Desktop / headless）
- **更深的可审计**：版本归因报告、回退即反馈信号（回退次数 → prompt 优化）

## 与社区的关系（诚实）

社区已有 dsh-shelf（verify/tree）、dsh-fork-graph、dsh-negative-ledger 等优秀插件。
我们的位置不是「又一个同类工具」，而是：

> **它们各自做业务层的一块；我们把它当作一整层来做，并且带生产级保证（写安全 +
> 深层体检 + 修复闭环）。**

工具可以被替换；层是生态基础设施。
